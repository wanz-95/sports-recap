# 体育赛事 AI 观赛助手，5分钟看懂这场比赛

一个面向"不懂球但被朋友拉着看比赛"的观众的 AI 赛后简报工具。

## 问题

体育比赛节奏快，普通观众看不懂战术跑位，错过关键瞬间只能等回放。赛后被朋友问"刚才那个球为什么重要"，往往答不上来。

## 用户场景

一个不太懂球、被朋友拉着看比赛的人，赛后想快速理解：

- 刚才发生了什么
- 为什么某个球重要
- 这场比赛的转折点在哪

## 解决方案

输入比赛文字直播或关键事件时间线，AI 生成一份"给外行看的赛事简报"：

- 用类比解释战术（比如"高位逼抢就像在对方半场抢钱包"）
- 标出 3 个转折点
- 支持用户追问

## 产品判断

### 为什么不用通用大模型直接问？

体育术语和实时数据需要约束，否则 AI 会编造不存在的进球。通用大模型在缺乏结构化输入时，容易"脑补"比赛细节。

### 怎么保证准确性？

用"赛事实时数据 + 模板化简报生成 + 用户反馈纠错"的方式，而不是纯靠模型自由发挥：

- 只能使用输入中明确出现的事件
- 数字（时间、比分）必须与输入完全一致
- 不确定的信息，标注"输入未提供"
